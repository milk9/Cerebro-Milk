# Prompts

Esta pasta contém prompts para IA, templates de conversação e instruções para diferentes casos de uso.

## Como usar
- Organize prompts por categoria (escrita, código, análise, etc.)
- Use nomes descritivos que indiquem o propósito do prompt
- Inclua exemplos de uso quando possível

## Estrutura sugerida
- `escrita-[tipo].md` - Prompts para escrita criativa
- `codigo-[linguagem].md` - Prompts para programação
- `analise-[area].md` - Prompts para análises
- `geral-[proposito].md` - Prompts de uso geral
